Automatic Pre-Update Backups

Before any code or dependencies are updated, DVM Nexus automatically takes an atomic snapshot of all active radio configurations (config.yml, talkgroup_rules.yml, rid_acl.dat, iden_table.dat).

If you ever need to revert to a previous state, navigate to the Config & History section where any prior snapshot can be restored with a single click.
